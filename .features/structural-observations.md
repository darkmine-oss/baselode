# Structural observation preservation

Preserve identity, original interval bounds and angle evidence in source
adapters. Reuse the attribute-expansion primitive for flat text and conflict
provenance; parse numeric projections separately with explicit diagnostics.
Point plotting uses the supplied depth; start depth is the documented default
for preserving GSWA conversions. Do not infer missing end depths or normalize
source angles during conversion. Structural schema metadata describes plane
angles rather than drillhole survey angles.

Validation: structural plotting regression with a long interval and a null
end depth; existing structural, raw-GSWA adaptor and schema parity tests.
